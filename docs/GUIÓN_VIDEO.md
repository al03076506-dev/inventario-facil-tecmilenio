# Guion sugerido para video demostrativo (3–5 minutos)

1. **Presentación:** describe que Inventario Fácil es una aplicación full stack desarrollada con HTML/CSS/JS, Node.js, Express y MongoDB.
2. **Estructura:** abre VS Code y muestra `backend`, `frontend`, `docs` y `postman`.
3. **Servidor:** muestra terminal con `npm run dev` y mensaje de conexión a MongoDB (solo cuando realmente funcione).
4. **Autenticación:** registra usuario, cierra sesión e inicia sesión con correo y contraseña.
5. **CRUD visual:** crea un producto, encuentra el registro, edítalo y elimínalo.
6. **Postman:** muestra GET público; intenta POST sin token (401); inicia sesión; crea, modifica y elimina enviando Bearer token.
7. **Seguridad y conclusiones:** explica `.env`, JWT y bcryptjs, y menciona la URL de GitHub y del despliegue si están disponibles.

**Importante:** graba el funcionamiento real de tu entorno; este guion no sustituye el video solicitado.
